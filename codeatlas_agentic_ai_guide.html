🏛️ 1. End-to-End System Architecture

CodeAtlas combines a high-performance **ASP.NET Core 9 Agent Engine** on the backend with an interactive **React 18 + SignalR Frontend** on the client side. Given a GitHub Repository URL and a technical prompt, CodeAtlas executes a fully autonomous software engineering workflow.

🔄 3. Step-by-Step Autonomous Workflow

1
Workspace Cloning & Isolation

The Git Workspace Manager clones the target repository into an isolated /workspaces/{taskId} folder on disk, establishing clean git state.

2
Roslyn AST Symbol Parsing

The Code Indexer uses Microsoft.CodeAnalysis.CSharp syntax trees to parse classes, interfaces, methods, and line numbers into an in-memory symbol graph.

3
Planner Agent Task Breakdown

The Planner Agent analyzes the user prompt and breaks it down into sequential sub-goals (e.g. 1. Locate Program.cs, 2. Add HealthChecks, 3. Validate Build).

4
Researcher Agent Context Lookup

The Researcher Agent queries Roslyn symbols to find exact file paths and method signatures needed for code modification.

5
Coder Agent & Code Edits

The Coder Agent performs precision code replacements and computes side-by-side Git diffs ready for Monaco Editor display.

6
Validator & Build Loop

The Sandboxed Execution Service runs dotnet build. If build errors occur, the traceback is passed back to the Coder Agent to self-correct until 0 errors remain!

📡 4. Real-Time SignalR WebSockets Protocol

To give developers complete visibility into what the AI agent is thinking and doing, the backend streams event notifications over SignalR WebSockets in real time: 

public interface IExecutionClient
{
    Task ReceiveAgentStep(AgentStepEvent step);
    Task ReceiveLogOutput(string taskId, string source, string message);
    Task ReceiveCodeDiff(string taskId, CodeDiffModel diff);
    Task ReceiveBuildOutput(string taskId, string outputLine, bool isError);
    Task ReceiveTaskStatus(string taskId, string status, string currentAgent);
}

As soon as the React frontend connects via new signalR.HubConnectionBuilder(), events stream into the UI without page refreshes!
